# Accordance

基于 Python 命令行交互的传统术数辅助分析系统。项目围绕八卦、六十四卦、京房纳甲、梅花易数、五行生克、月日旺衰、世应用神等规则，提供传统文化研究与象征化决策参考。

> 本项目仅用于传统文化研究、术数规则整理与命令行工程练习，不替代现实证据、专业意见、法律/医疗/金融建议，也不鼓励过度依赖占断结果。

## 功能概览

- 六爻详占：动态时间起卦、京房纳甲、世应、六亲、六神、十二长生、旬空、月破、日破、动变回头生克。
- 梅花易数：体用生克、互卦、错卦、综卦、互卦错综视角、外应记录与提示。
- 用神系统：根据问题语义推断用神，并分析原神、忌神、仇神、伏神、综合爻力与传统依据链。
- 三爻快占：适合临时问题的单卦快速判断。
- 当日气运：按日基准生成当日行事参考，避免短时间反复刷新。
- 姓名起卦：基于姓氏、名字笔画数起卦。
- 寻物专项：结合八卦方位、物象、颜色、环境和物品信息给出寻找建议。
- 二选一辅助：分别为两个选项起卦，综合体用、卦象、风险语义与纳甲证据链进行对比。
- 问题历史：依据“初筮告，再三渎，渎则不告”的原则，在同一会话中提醒重复占问。

## 项目结构

```text
.
├── Accordance/              # 实际 Python 应用目录
│   ├── main.py              # 命令行入口
│   ├── config/              # 八卦、六十四卦、纳甲、五行规则数据
│   ├── core/                # 起卦、装卦、解卦、气机与历史逻辑
│   └── modules/             # 六爻详占、快占、姓名、寻物、二选一等功能模块
├── .gitignore
├── .gitattributes
└── README.md                # GitHub 首页说明
```

当前仓库根目录用于 Git 版本管理，实际运行目录是 `Accordance/`。这种结构是合理的：根目录承载仓库说明和工程配置，子目录承载应用源码。

## 运行方式

进入项目根目录后运行：

```bash
cd Accordance
python main.py
```

如果你的系统中 `python` 指向 Python 2，请改用：

```bash
python3 main.py
```

## 规则取向

项目尽量把传统术数规则拆成可审阅的工程模块，而不是只输出一句断语。核心判断会尽量展示依据，例如：

- 卦名、卦辞、核心意象；
- 体卦、用卦及五行生克；
- 世应、六亲、六神、纳甲干支；
- 旬空、月破、日破、刑冲合害；
- 用神、原神、忌神、仇神、伏神；
- 动爻、变卦、回头生克；
- 现实校验提醒。
