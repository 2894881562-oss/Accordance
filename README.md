# Accordance

基于 Python 命令行交互的传统术数辅助分析系统。以《周易》六十四卦为体，京房纳甲筮法、梅花易数、四柱八字与奇门运筹为用，融通彖象二传、卦身神煞、用神生克、十神关系、九宫八门，提供传统文化研究与象征化决策参考。

> 本项目仅用于传统文化研究、术数规则整理与工程练习，不替代现实证据、专业意见、法律/医疗/金融建议。

## 核心取向

- **规则有据**：五行生克、六冲六合、进神退神、旬空月破等规则均考据自《增删卜易》《卜筮正宗》等经典，不作凭空杜撰。
- **依据可审**：每次解卦输出完整的证据链——彖传纲领、大象传警句、纳甲装卦表、用神原忌仇伏神、爻力评分、体用生克、动变回头、卦身神煞。
- **人为本**：内置"易为君子谋"的哲学提醒——卦是镜鉴，人为本；吉凶不在卦，德行与选择决定走向。
- **实占校验**：每次六爻类输出补充传统依据与现实校验清单，明确卦象是趋势与警示，不替代事实、证据和专业意见。
- **简短结论**：各功能先显示面向普通用户的一两句摘要，给出倾向、行动与现实提醒；CLI 默认不展开，用户确认后再看专业断语与完整依据。
- **蒙卦底线**：贯彻"初筮告，再三渎，渎则不告"的术数伦理——同义问题跨会话去重，同题/高度相似/近似相关分层拦截，持久化记录不可绕过。
- **先审所问**：起卦前先校准问类、用神、时间尺度、方法匹配与现实补充信息，减少问法含混导致的取用偏差。

## 功能概览

### 1. 六爻详占（京房纳甲筮法）
动态时间起卦 → 完整装卦 → 多维解卦：
- 卦宫五行、世应定位、纳甲干支
- 六亲、六神、十二长生、纳音五行
- 节气月建、旬空、月破、日破、暗动
- 动变回头生克、进神退神（含土行四库循环）
- **卦身**（月卦身 + 世身）——事之头绪与卦主身心
- **神煞**（天乙贵人、文昌、驿马、桃花、禄神、华盖、劫煞、灾煞）
- 爻力综合评分、地支刑冲合害
- **依据与校验**：输出京房纳甲、增删卜易、卜筮正宗、梅花体用的调用链，并按财、病、文书、婚恋、寻物等问类给出现实核验点
- **象义校准**：每卦叠加主轴、宜用与风险边界，避免只按零散关键词断卦
- **简短结论**：先用一句话给出倾向判断、行动建议和现实核对点，详细分析按需展开

### 2. 用神证据链
- 根据问题语义自动推断用神（妻财/官鬼/父母/子孙/兄弟），细分财货、官职、疾病、医药、婚恋、文书、寻物、出行等问类
- 分析原神（生用神者）、忌神（克用神者）、仇神（克原神生忌神者）
- 用神不现时查伏神（按本宫首卦取伏，分析飞伏生克关系）
- 用神多现时按传统优先级取用（发动 > 持世 > 旺相不空破 > 近世者）
- 输出传统依据链 + 现实校验提醒

### 3. 梅花易数体用生克
- 体用识别、五行生克、旺相休囚死
- 互卦、错卦、综卦、互之错、互之综
- 八经卦体用生克象义（乾生体功名有喜、兑克体口舌纷争等）
- 外应记录与克应分析

### 4. 三爻快占
先给短期可执行的简短结论，用户确认后再展开爻象分析、旺衰评估与阴阳进退建议。三爻只用于紧急、单点、短期判断；重大决策或需看前因后果时改用六爻详占。

### 5. 当日气运
按农历年月日生成当日行事参考，同日结果稳定不变，并补充一句当天行事基调。

### 6. 姓名起卦
姓氏、名字笔画数（康熙字典笔画）起六爻重卦，先给通俗结论，再按需展开纳甲体系解卦。

### 7. 寻物专项
结合八卦方位、物象、颜色、环境信息综合推理。先明确优先找哪里、是否扩大范围；用户确认后再展开三爻方位与物象依据。范围大或不确定时提示改用六爻详占。

### 8. 二选一决策
双卦对比先给出“A / B / 暂缓”的短判断，再按需展开体用、风险语义与用神评分依据。

### 9. 四柱八字基础分析
按公历出生日期时间生成四柱，输出年、月、日、时干支、日主、十神、藏干、五行分布、日主强弱、年干/时干内外气质、四柱阶段提示与“治/用”格局倾向。已补充喜忌取向、岁运同参、大运顺逆、近似起运、当前流年与临界时辰候选对照。该功能强调关系双向性：生助、克制、掌控、输出、竞争都不是单向得失，只作自我观察与传统文化研究参考。

### 10. 奇门运筹分析
按当前时间生成工程化简化九宫盘，合参九宫、八门、九星、八神与三奇六仪，输出方位运筹、时机运筹、格局运筹和慎用方位。已补充遁甲核心层：按当前时干支定位六甲旬首、甲遁六仪、藏甲宫、值符值使参照、庚格风险、三奇助力与主客态势，用于判断核心目标应藏于何处、如何避开冲克、借外围助力推进，或转入护主守势。报告会进一步生成“格局诊断”“主客攻守矩阵”“行动方案”“执行闸门”“综合裁决”和“置信度校准”，先按伏吟、反吟、空亡、吉凶门与门星神一致性判断整盘推进度，再把主位承接、客压识别、转化铺垫、禁区止损，以及护甲、借奇、取门执行、避庚控险、现实复核整理成分步清单，并给出可执行/小步推进/先试探/暂缓强攻的行动信号；执行前还会列出必查项、推进条件、停止条件和降级路径；最后统一裁决为分层推进、低成本试点、等待窗口或暂缓执行，并按冲突、空亡、庚格、时机差和信息缺口给出置信度；同时比较当前、下一、再下一三个时辰窗口，提示更适合现在动、等一等还是继续铺垫。该功能适合谈判、竞争、出行、项目推进、资源调度等现实行动参考；不实现完整拆补、置闰、超接、符使飞布和历法精算，也不把动漫《一人之下》的“风后奇门”设定作为传统规则。

### 11. 问题历史（跨会话持久化）
- JSON 文件落盘（`.data/question_history.json`），关程序重开仍有效
- 中文语义级相似度检测（同义词归一 + 核心词提取 + 加权 Jaccard）
- 分层时间规则：同题复问15天内拦截、30天内警告；高度相似7天内拦截、15天内警告；近似相关7天内提醒
- 历史记录压缩：紧凑 JSON 写入，单条字段截断，默认保留最近120条并控制在约96KB以内
- 蒙卦训诫原文展示 + 三条用户自主选择

### 12. 起卦法选择
- 起卦法选择器：根据问题文本推荐六爻详占、三爻快占、姓名起卦、当日气运、寻物专项、二选一决策、四柱八字或奇门运筹
- 问事校准：六爻、三爻、寻物和二选一入口会先提示问类、用神、时间尺度、方法边界与现实补充点

## 运行方式

```bash
cd Accordance
python main.py
```

### CLI 测试历史

命令行会默认把复问历史写入 `Accordance/.data/question_history.json`。功能测试时建议临时重定向或禁用历史，避免测试问题污染正式记录：

```powershell
# 重定向到测试历史文件
$env:ACCORDANCE_HISTORY_FILE = "$PWD\.data\test_question_history.json"
python main.py

# 或完全禁用本次历史读写
$env:ACCORDANCE_HISTORY_DISABLED = "1"
python main.py
```

这些环境变量只影响当前终端进程；正式使用时新开终端或清空变量即可恢复默认历史。

## 手机网页运行

本项目已提供移动端 Web 入口，核心规则仍由 Python 引擎计算，手机浏览器只负责输入与展示。
需要凝神的问事入口会在浏览器和服务端同时校验默念步骤；资料变更后必须重新凝神，直接调用 API 也不能用零值绕过。

### 本机/同一局域网运行（当前推荐）

Windows 可直接运行根目录脚本：

```powershell
.\start_local_web.ps1
```

脚本会显示可尝试的电脑局域网 IP。终端保持开启时，同一 Wi-Fi 或同一手机热点下的手机访问：

```text
http://电脑局域网IP:8000
```

也可以手动启动：

```bash
pip install -r requirements.txt
cd Accordance
uvicorn web.app:app --host 0.0.0.0 --port 8000
```

注意：

- 电脑终端关闭、电脑休眠、断网或切换网络后，手机端会停止访问。
- `172.*`、`192.168.*`、`10.*` 这类地址通常只在同一局域网可用，外地用户不能直接打开。
- 本机 Web 历史默认保存在 `Accordance/.data/web_clients/`，该目录已忽略，不会进入 GitHub。

### Docker 运行（可选）

```bash
docker compose up -d --build
```

若从旧版 root 容器升级且已经存在匿名历史卷，首次切换到本版本时先执行一次：

```bash
docker compose run --rm --user root accordance-web chown -R accordance:accordance /data
```

新建数据卷不需要这一步。

访问：

```text
http://电脑或服务器IP:8000
```

### 隐私与历史

- 无需注册登录，不提供用户互相查看记录的入口。
- 每台设备首次访问会获得匿名 `client_id`，历史记录只按该匿名设备隔离保存。
- Web 历史默认保留最近 120 条并控制在约 96KB 内，沿用蒙卦复问提醒规则。
- `.data/` 属于本地隐私数据目录，已加入忽略，不应提交到公开仓库；本机 Web 匿名历史在 `Accordance/.data/web_clients/`。
- 服务日志不记录用户问题正文；页面也不暴露服务端历史文件路径。
- 应用统一拒绝超过 64KB 的请求体，并设置禁止嵌入、同源内容策略和摄像头/麦克风/定位禁用头；即使不经过 Caddy 也保持相同边界。
- 匿名设备 Cookie 在本机 HTTP 下保持可用，经 HTTPS/Caddy 访问时自动增加 `Secure`，并始终限制为 HttpOnly、SameSite=Lax、全站路径。

## 规则体系

### 术数经典依据
- **卦序与世应**：京房八宫卦变体系（一世→五世→游魂→归魂）
- **纳甲干支**：乾纳甲壬、坤纳乙癸、震庚、巽辛、坎戊、离己、艮丙、兑丁
- **六冲卦**：据《增删卜易·六冲章》，八纯卦 + 天雷无妄 + 雷天大壮，共十卦
- **六合卦**：据《增删卜易·六合章》，核心八合（否、节、贲、豫、旅、复、泰、困）
- **进神退神**：据《卜筮正宗·进神退神章》，木火金水各二 + 土行四库循环（丑→辰→未→戌→丑），辰戌互化、丑未互化判为反吟
- **卦身**：月卦身（世爻阴阳起子午法）+ 世身（世爻地支定爻位法）
- **神煞**：天乙贵人、文昌、驿马、桃花、禄神、华盖、劫煞、灾煞，皆按日干/日支查
- **旬空**：甲子旬戌亥空、甲戌旬申酉空，依此类推，基于儒略日精算日干支
- **暗动**：静爻被日辰冲为暗动（旺相有力或休囚日破）
- **奇门运筹**：以九宫、八门、九星、八神、三奇六仪做工程化简化盘，强调固定时空下的择方、择时、攻守布局；格局诊断层近似识别伏吟、反吟、空亡、吉凶门和门星神同向度；遁甲层按六甲旬首查甲所遁之六仪，标出藏甲宫、值符值使、庚格风险、三奇助力、主客态势、主客攻守矩阵、分步行动方案、执行闸门、综合裁决和置信度校准；择时层比较当前、下一、再下一时辰窗口，辅助判断现在行动或暂缓铺垫；传统奇门不改动格局，风后奇门属文艺设定不纳入计算

### 解卦输出层次
CLI 每次先显示简短结论，压缩为倾向判断、现在该怎么做、现实上要核对什么；默认不展开。用户确认查看详细分析后，再按以下层次展示：
1. **卦象概要**：卦名、卦辞、卦意、大象传、彖传
2. **纳甲装卦**：世应、纳甲、六亲、六神、旬空月破、爻力评级
3. **动变与互错综**：动爻爻辞、变卦、互卦、错卦、综卦
4. **体用生克**：体用关系、五行旺衰、所主吉凶事项
5. **用神系统**：用神推断依据、原神忌神仇神现状、伏神飞伏关系、系统评分
