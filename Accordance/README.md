# Accordance 应用目录

这里是项目的实际 Python 源码目录。GitHub 仓库首页说明请查看根目录的 `README.md`。

## 运行

在当前目录执行：

```bash
python main.py
```

或从仓库根目录执行：

```bash
cd Accordance
python main.py
```

## 目录说明

```text
config/    八卦、六十四卦、纳甲、五行等基础数据
core/      起卦、装卦、解卦、气机、问题历史等核心逻辑
modules/   六爻详占、三爻快占、姓名、当日、寻物、二选一等入口模块
main.py    命令行主入口
```

本项目仅作传统文化研究与象征化参考，不替代现实分析和专业意见。
