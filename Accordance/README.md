# 周易风水决策系统

## 一、项目简介

本项目是一个基于 Python 命令行交互的传统术数辅助分析系统，围绕八卦、六十四卦、五行生克、旺衰状态、方位物象、起卦气机等内容，提供传统文化研究与象征化决策参考功能。

系统定位为：

```text
传统文化研究工具
象征化分析辅助工具
Python 命令行交互项目
模块化工程练习项目
```

## 二、核心能力

- 六爻详占：动态时间起卦、京房纳甲、世应、六亲、六神、十二长生、旬空、月破、日破、动变回头生克。
- 梅花易数：体用生克、互卦、错卦、综卦、互卦的错综视角、外应记录与提示。
- 用神系统：按问题语义推断用神，并给出原神、忌神、仇神、伏神、综合爻力与传统依据链。
- 专项模块：三爻快占、当日气运、姓名起卦、寻物专项、二选一决策辅助。
- 理性边界：所有结果均为传统文化研究与象征化参考，不替代现实证据、专业意见或风险评估。

## 三、运行方式

```bash
python main.py
```

建议在 `Accordance` 目录内运行，按命令行菜单选择对应模块。
